## 出题要求

### 数量与类型

为上述 id **各写 1 条**（允许 skip），共 150 条。类型二选一：

- **`direct`（约一半）**：可以使用标题里的技术术语，但**必须重造句式、补充场景**。
  例：标题「节点心跳」→ `Kubernetes 里节点的存活状态多久上报一次？`
- **`paraphrase`（约一半）**：**不出现标题里的技术术语**，用同义表达或描述现象。
  例：标题「节点心跳」→ `集群怎么判断某台机器是不是已经掉线了？`

### 硬性约束

1. 长度 **10~35 个汉字**（含标点不超过 40 字符）；
2. 复用限制：
   - `paraphrase`：禁止出现标题里连续 **4 个汉字**及以上的片段；
   - `direct`：禁止出现标题里连续 **6 个汉字**及以上的片段（不能整句照搬）；
   - 两种都禁止把标题**原样改成问句**。
3. 每条只问**一个**问题，不要并列两个问句；
4. 不要出现"本小节""这段内容""如下图所示"之类的元指代；
5. 用**真实用户会说的话**，可以口语化，不要写成考试题。

### 什么时候 skip

- 标题不足 4 个字且看不出具体主题（如「设计」「下一步」）；
- 标题是导航/示例/罗列性质（如「执行 `CREATE TABLE` 语句」）；
- 你能想到的任何问题都只能靠猜正文，且猜错概率很高。

**预计 skip 15~25 条是正常的**，不要强行填满。

## 输出格式

只输出一个 JSON 数组：

```json
[
  {"id": 0, "type": "paraphrase", "query": "容器之间要互相通信，底层是谁在负责搭这套网络？"},
  {"id": 8, "skip": true, "reason": "标题只有「设计」两个字，无法判断是哪个组件的设计"}
]
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 对应上表的 id |
| `type` | 非 skip 时必填 | `direct` 或 `paraphrase` |
| `query` | 非 skip 时必填 | 问题文本，10~35 汉字 |
| `skip` | 否 | 布尔，true 表示放弃这条 |
| `reason` | skip 时必填 | 一句话说明为什么放弃 |

## 自检清单

- [ ] 150 个 id 都出现且只出现一次
- [ ] 没有一条包含标题里超过限制的连续汉字片段（paraphrase 4 字 / direct 6 字）
- [ ] `paraphrase` 里没有出现标题的技术术语
- [ ] 每条 10~35 汉字，且只有一个问号
- [ ] skip 的条目都写了 reason

## 我们怎么用这批数据

1. 先跑脚本校验格式（复用率、长度、类型配比）；
2. 我会**逐条回到正文核对"这一节能不能回答它"**——第一批 32 条里有 5 条是标题
   没覆盖到的（比如标题「工作负载」讲的是 Lease 领导者选举，不是"让容器持续运行"），
   这类会被剔除；
3. 从"能回答"的里面筛出 **100 条**，与内部的 100 条组成 50:50 的评测集；
4. 筛掉的不是你的问题——那是"标题信息量不足"，本身就值得统计。
